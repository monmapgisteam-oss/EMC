# Уулын цулын шилжилт

Ил уурхайн сар бүрийн уулын цулын шилжилтийг 3D-д харуулах вэб апп.

**Next.js 15 (App Router) · React 19 · TypeScript · ArcGIS Maps SDK for JavaScript 4.34 (`@arcgis/core`)**

## Ажиллуулах

```bash
npm install
npm run dev      # http://localhost:3100
```

Бүтээгдэхүүний горим:

```bash
npm run build
npm run start    # http://localhost:3100
```

## Зарчим

**ArcGIS сервисээс зөвхөн геометр авна.** Дэлгэц дээрх бүх тоо
`mes1-12 нэгтгэл 2023 ArcGIS.xlsx` файлын **«Нийт орд arcgis»** sheet-ээс
уншигдана. Курсор феатур дээр очиход тухайн феатурыг Excel-ийн харгалзах
мөртэй **кодоос** холбож харуулна.

### Холболтын түлхүүр

| Excel | → | Феатур |
|---|---|---|
| `Түвшин` (1175…1460) | → | зөвхөн Excel-ийн бүтцийн багана — зүүн рейлээс сонгоно |
| `Блок = БҮ` | → | `Multipatch_EMC` дахь `type1 = 1` (54 феатур) |
| `Блок = 12 / 14 / 8a / 2б` | → | `RefName` (3D) / `dugaar` (2D) |
| багана «9а, 8, 9 овоолгод» | → | Овоолго 9а, Овоолго 8, Овоолго 9 |
| багана «9б овоолгод» | → | Овоолго 9б |
| багана «Овоолго №1, 4, 11» | → | хоосон чулуулгийн овоолгууд |

Excel-д `8a` (латин **a**), сервист `Овоолго 8а` (кирилл **а**) байдгийг
`lib/config.ts` дахь `BLK2PILE` / `PILE2COL` хүснэгтээр нормчилсон.

## Тэмдэглэлүүд

**ArcGIS + Next.js.** `@arcgis/core` бол бүхэлдээ browser талын сан.
`MineScene` нь `dynamic(..., { ssr: false })`-ээр ачаалагдана. Assets-ыг
`node_modules`-оос хуулахгүйгээр CDN-ээс авахаар `esriConfig.assetsPath`-ыг
тохируулсан.

**Суурь зураг.** Esri-гийн вектор суурь зураг API key шаарддаг тул түлхүүр
шаардахгүй `services.arcgisonline.com`-ийн кэшлэгдсэн зургуудыг ашиглаж байна.

**Multipatch_EMC-ийн атрибут.** Тэр сервисийн I3S кэш дээр атрибутын буфер
шилжсэн: `hitTest`-ээс `ner` огт ирэхгүй, `type1` нь хог утга (1081751420),
`OBJECTID` нь FeatureServer-ийн `FID`-тэй таарахгүй. Сервис публиш хийхэд
гарсан алдаа тул клиентээс засах боломжгүй. Тиймээс барилгын атрибутыг
курсорын байрлалаар **FeatureServer** рүү цэгэн асуулга явуулж авна
(`bldLookup`, байршлаар кэшилнэ). Сервисийг дахин публиш хийвэл энэ тойрох
шийдэл хэрэггүй болно.

**Симбологи.** `Multipatch_EMC` болон `Нийт_овоолго_2026` хоёрын renderer-ийг
**дарахгүй** — сервис дээрх өөрсдийнх нь симбологи ажиллана. (Тэдгээрийн
uniqueValue утга нь тэмдэгт мөр хэлбэртэй тул тоогоор дарж бичих гэвэл бүх
феатур `defaultSymbol` рүү унаж саарал болдог.)

**Тусгаарлах горим.** Толгойн «Зөвхөн уурхай» товч эсвэл пит дээр дарвал
суурь зураг, гадаргуу, барилга, овоолго, зам унтарч, зөвхөн питийн multipatch
бараан дэвсгэр дээр үлдэнэ. Шууд нарны сүүдэр асч хаялбар, берм, налуу
тодорно. Гарахдаа Esc.

**Машины аюулын анхааруулга.** `HAZARD_MAP/FeatureServer/0`-ийн геометрийг
WGS84-өөр ачаалж, машины хөдөлгөөн бүрт бүсэд байгаа эсэхийг шалгана.
`code` 1 үед ногоон хонх, 2 үед улбар шар хонх, 3 үед улаан анхааруулах
тэмдэг тогтмол харагдана. Газрын зураг дээрх тэмдэг 18 пикселийн хэмжээтэй.
Давхцсан бүсээс хамгийн өндөр түвшнийг сонгож, бүсээс гарахад тэмдэг арилна.
Бүсийн зураг нуугдсан ч анхааруулга ажиллана; машины давхаргатай хамт нуугдана.
Сервис ачаалахгүй бол газрын зураг дээр төлөв болон дахин ачаалах товч гарна.

**Haul Truck загвар.** Хөдөлж буй болон зогсоолын бүх машин шар будаг,
хар дугуй, тусдаа бүхээг, шат, хашлага, задгай тэвштэй 3D загвар ашиглана.
Ачаатай машин тэвшин дотор хүдэртэй, хоосон машин задгай тэвштэй харагдана.
Загварын материалуудыг чиглэлийн өнгөөр будахгүй; аюулын түвшин нь тусдаа
тэмдэг болон картын өнгөөр харагдана. `npm run data:truck` командаар
`public/data/truck.glb`, `public/data/truck-loaded.glb` файлуудыг дахин үүсгэнэ.
Явж буй болон зогссон машин дээр курсор очиход доод карттай нь ижил
`TRUCK N` дугаар харагдана. Экскаваторууд тусдаа 1–3 дугаартай.

**Экскаватор.** Зогсоолын гурван машины хажуугийн тэгш ажлын талбайд шар
гинжит экскаватор байрлана. Байрлал нь тогтмол, сум нь машины тэвш рүү харна.
Шанаганы ам их бие рүү дотогш харсан, шүд доош чиглэсэн;
хонхор дотор тал, ёроолын багахан шороо нь нээлттэй хэвээр.
«Давхарга → Экскаватор»-оор харуулах эсэхийг удирдана. Байрлалын тохиргоо
`lib/excavators.ts`-д; `npm run data:excavator` командаар
`public/data/excavator.glb` загварыг дахин үүсгэнэ.

**Хаягдлын урсгал.** Газрын зургийн дусал дүрстэй «Урсгал харах» товчоор
газрын гадаргуугаас 30 м доорх, 2 м диаметртэй бүтэн ногоон хоолойг
газрын орчинтой нь харна. Эхэндээ хоолой тунгалаг биш, газрын тунгалаг
байдал 65% байна. «Тунгалаг» нь хоолойн ханыг нэвт харуулж, «Зүсэлт · Slice»
нь ойрын хэсгийн газар болон хоолойн ханыг зүсэж доторх урсгалыг нээнэ.
Газрыг ArcGIS SliceAnalysis-аар, хоолойн ханыг бодит мэшийн зүсэлтээр
нээнэ; усны геометр, хөдөлгөөн хэвээр үлдэнэ. Хоолой болон газрын
тунгалаг байдлыг тус тусад нь 0–100% тохируулна. «Урсгал руу ойртох»
нь доторх ногоовтор шингэн, намхан долгион, үйлдвэрээс далан руу урсах
цагаан хөөсийг харуулна. «Газар доорх шугам» нь орчныг дахин багтаана.
Хаах эсвэл Esc нь зүсэлтийг арилгаж, өмнөх камер, газрын төлөвийг сэргээнэ.
Урсгалын хөдөлгөөн нь сарын тоонд суурилсан дүрслэл бөгөөд хэмжсэн
гидравлик хурд биш; тэг утга болон нуугдсан давхаргад хөдөлгөөн зогсоно.
Усны давтагдах хөдөлгөөнт хээг `python tools/build_tailings_water.py`
командаар үүсгэнэ (NumPy, Pillow, imageio_ffmpeg шаардлагатай).

**Бүтэн дэлгэцийн машины картууд.** Газрын зургийн бүтэн дэлгэцийн товчийг
дарахад доор нь машины ачаалал, аюулын түвшин, налуу, хамгийн ойрын машин
хүртэлх хэвтээ зайг харуулна. Картууд хагас секунд тутам шинэчлэгдэнэ,
хэвтээ гүйлгэж бусад машиныг үзнэ; карт дээр дарвал тухайн машин руу очно.
Налуу нь сарын DWG өндөр ба уурхайн гаднах газрын өндрөөс машины чиглэлийн
дагуу тооцсон утга бөгөөд мэдрэгчийн хэмжилт биш. Өндөр олдохгүй бол `—`.

**DWG.** `\\SARUUL\Share\EMC\dwg\CMK_2023MM.DWG` — сар бүр яг 1 multipatch,
Z 1167–1523 м, солбицол тодорхойлогдоогүй тул **UTM 48N (EPSG:32648)** гэж
үзсэн. Питийн хотгорыг `Fill(DEM) − DEM` -ээр илрүүлнэ (2.99 км², 173 м гүн).

## Тодруулах шаардлагатай

1. **Сар 6, Түвшин 1415** — `Блок = 2б` байхад 140 мян.тн нь «Овоолго 14»
   баганад бичигдсэн. Аль нь зөв бэ?
2. `Нийт уулын цул` (м³) нь хүдэр + хоосон чулуулагтай нийлэхгүй байна —
   өөр суурьтай юу?
3. БҮ-д `type1 = 1`-ийн бүх 54 феатур орох ёстой юу?
4. Хаягдлын далангийн сервис **2024/01**-ээс эхэлдэг — 2023 оны хэмжилт бий юу?
5. Ил уурхайн multipatch сервис публиш хийгдээгүй — одоогоор локал GLB.
